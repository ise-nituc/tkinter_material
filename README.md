# PythonとTkinterでGUIアプリを作ろう

## 1. はじめに

PythonのGUIライブラリ「Tkinter」を使って、ウィンドウやボタンで操作できるアプリを作ります。GUI（Graphical User Interface）の基礎を練習し、日常生活で「あれば便利」と思う自分だけのアプリを完成させましょう。

Pythonの変数・条件分岐・繰り返し・関数は、必要に応じて復習してください。

## 3. 準備と実行方法

Python 3と、コードを書くためのエディター（講義ではVS Code）を用意します。VS Codeでこのフォルダーを開き、ターミナルで次を実行してください。

```powershell
python -m tkinter
```

確認用のウィンドウが開けば準備完了です。Tkinterが使える環境では、解答例を動かすための追加パッケージは不要です。ウィンドウが開かない場合は、授業で使うPython環境を選択し、Tcl/Tkが入っているか確認してください（[Python公式ドキュメント](https://docs.python.org/ja/3/library/tkinter.html)）。

解答例は、このフォルダーを作業場所として1つずつ実行します。

```powershell
python src/練習1.py
```

VS Codeでは、実行したいPythonファイルを開いて「Run」→「Run Without Debugging」からも実行できます。確認後はウィンドウの「×」で終了します。

## 4. GUIの基本

GUIは、クリックやキー入力などの「イベント」をきっかけに、対応する関数（ハンドラ）を実行します。まずは次のコードを新しいPythonファイルに保存し、実行してみましょう。

```python
import tkinter as tk


def say_hello():
    label.config(text="こんにちは！")


root = tk.Tk()
root.title("はじめてのGUI")
root.geometry("300x150")
root.columnconfigure(0, weight=1)

label = tk.Label(root, text="ボタンを押してください")
label.grid(row=0, column=0, padx=10, pady=10)
button = tk.Button(root, text="あいさつ", command=say_hello)
button.grid(row=1, column=0, pady=10)

root.mainloop()
```

`Tk()`でウィンドウを作り、`Label`や`Button`などの部品を`grid()`で配置します。`mainloop()`は操作を待ち、画面の更新やイベントの処理を続けます。`command=say_hello`には、括弧を付けずに関数を渡します。

## 6. 自分のアプリを作る

1. 「誰が、何に困っているか」を決めます。例：勉強時間の記録、持ち物の確認、買い物の予算計算。
2. アイデアを新しさと実現のしやすさで比べ、時間内に作れるものを選びます。講義資料のHow-Now-Wowマトリクスを参考にしてください。
3. 紙に画面を描き、必要な`Label`・`Entry`・`Button`・`Frame`を決めます。
4. 自分のプログラムを`src/main.py`などの名前で新規作成し、まず画面を配置します。
5. ボタンに処理を付けます。入力欄は`Entry.get()`で読み取り、結果は`Label.config()`や`messagebox`で表示できます。
6. 正常な入力に加え、空欄や数値以外の入力でも試し、画面サイズを変えたときの配置を確認します。

最初は1つの機能を完成させ、余裕があれば機能を増やしましょう。教科書の事例は参考にしながら、自分の目的に合う機能や工夫を加えてください。
